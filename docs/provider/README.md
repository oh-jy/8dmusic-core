# 可导入的 Provider

这些配置独立存放在文档目录，不随应用自动加载。打开应用中的「管理来源 / 导入」，选择 JSON 文件，或用手机扫描对应 PNG；预览来源及域名后自行确认导入。手机本地已有 JSON 时可直接选择文件；扫码需要将图片显示在另一块屏幕上。

| 来源 | JSON | 二维码 | 说明 |
| --- | --- | --- | --- |
| Apple iTunes 歌曲试听 | `apple-itunes-preview.json` | `apple-itunes-preview.png` | 搜索接口返回的仅是试听片段，不是完整歌曲；不支持翻页。 |
| 央广电台直播 | `cnr-radio.json` | `cnr-radio.png` | 包含中国之声、音乐之声、经典音乐广播和经济之声，各使用一条 HTTPS 直播线路。 |
| 试听与央广组合 | `combined-starter.json` | `combined-starter.png` | 一次确认导入以上两个来源；需要支持多来源包的新版本。 |
| 原版全量 FM | `all-fm.json` | 无 | 原版 173 条电台、581 条线路（含备用），文件导入；需要支持备用线路的新版本。 |

二维码直接包含对应 JSON 的内容，无须下载远程配置。来源由第三方提供，可能因地区、网络、接口或授权变化而不可用；导入前请自行确认平台条款以及播放、录音、导出等用途所需权限，导入不代表取得授权。Apple 试听片段的使用还应遵守 Apple 对预览内容的相关条款。

全量 FM 来自项目 `backup` 分支的旧目录，未逐条验证当前可用性；其中含 HTTP 线路，导入时会提示明文风险。它的体积超过单个二维码的容量，因此须通过文件导入；上面的组合二维码仅包含试听及四台央广直播，不包含全量 FM。

2026-11-09 检查：上述搜索接口返回了歌曲试听地址，四个电台地址返回了 HLS 播放列表；这不代表设备上播放、听感或权限已经验证。Apple 搜索结果中的试听时长及可用性由服务方决定，应用当前无法自动识别试听。需要完整歌曲的服务须直接在搜索结果中提供合法可访问的播放地址；当前格式不支持登录、单独解析播放地址或复杂签名，不能直接兼容网易云、QQ 等全部平台。

配置格式和安全限制见 [`../provider-format.md`](../provider-format.md)。请勿在配置或二维码中放入账号凭据。

## 广播迷 TV 线路排查（历史）

广播迷直播由独立 JAR Provider 提供，更新应用后还需重新导入合并 Provider。CCTV1 的安徽线路通过脚本映射到合肥广电页面；Provider 解析该页面的视频地址，交给应用原生视频视图播放。此解析需要 Provider 声明 `app.hfbtc.cn` 域名。

2026-11-24 检查：原安徽线路解析后的 HLS 和连续两段 MPEG-TS 视频数据请求成功，设备播放仍需单独验收。同频道的「CCTV」线路在设备上报 `SSLPeerUnverifiedException`，上游媒体域名 `tencent.live.cbncdn.cn` 与证书不匹配；「央视频」线路的媒体主机 `yd.pull.xzbjhuz.cn` 在电脑直连测试中超时。更新 Provider 无法修复第三方服务器的证书或连通性问题。

这两条原线路仍保留。CCTV1 增加明确标注的「官方网页直播」选项；原生播放失败时可选择官网回退，避免自动进入同一失效源的网页后再次显示笼统下载错误。官网回退使用网页播放器，不代表原线路已恢复，也不关闭证书校验。

## 游魂 TV 直播目录

游魂目录和参考项目 `vbskycn/iptv` 的 IPTV4 清单首次获取后保存在应用私有目录，使用「更新目录」手动更新。两份清单在「全部频道」中按规范化后的相同名称合并线路；参考项目的原始链接在当前电脑网络不可用，改用其公开 GitHub 内容 API。TV 线路会自动探测，优先尝试最先响应的可识别线路，并在播放错误、准备超时或长时间缓冲时切换其他线路。播放及切换仍须设备验证。

应用 2.25.2 起，更新合并 Provider JAR 后，首页视频按钮直接打开电视直播聚合目录，目录中可直接打开视频链接、历史与收藏。广播迷不再包含在默认合并包中，也不再提供 FM 或 TV 入口；已导入的旧插件不会被自动删除。

游魂目录使用当前公开地址 `https://www.iyouhun.com/tv/zb`，按分类合并同名频道的不同线路，每页 100 个频道，没有 1000 条总量上限。线路自动选择并直接原生播放，不将裸视频地址作为网页播放器。第三方线路存在失效、超时及地区差异，目录收录不代表全部线路可用。

2026-11-24 检查：用户提供的 `/tv/fty` 跳转到首页，公开直播 TXT 可读取。实际 Java Provider 解析出 25 个有效分类、1304 个合并频道，并遍历所有分页检查 IPC 响应大小；抽样 CCTV1 的第 2 条、CCTV13 的第 3 条线路返回了实际 MPEG-TS 分片，其他抽样线路存在超时或错误。设备端尚待解锁、导入及播放验收。饭太硬 `.net/tv` 和 `.cc/tv` 返回非明文配置，本轮未执行其第三方 JAR。

## 加密来源文件

支持加密文件的新版应用可导入 `.8dp` 文件。使用 JDK 17 或更高版本，在交互式终端运行：

```powershell
java docs/provider/EncryptProvider.java docs/provider/all-fm.json all-fm.8dp
```

程序会要求输入并确认密码，不会覆盖已有输出文件。导入时输入同一密码；文件使用 PBKDF2-HMAC-SHA256 派生密钥及 AES-256-GCM 认证加密。文件加密不证明来源可信，导入预览仍需核对来源。应用保存的来源配置仍是应用私有数据，文件加密不等同于对应用内部数据或账号凭据加密。
