# 可导入的 Provider

这些配置独立存放在文档目录，不随应用自动加载。打开应用中的「管理来源 / 导入」，选择 JSON 文件，或用手机扫描对应 PNG；预览来源及域名后自行确认导入。手机本地已有 JSON 时可直接选择文件；扫码需要将图片显示在另一块屏幕上。

| 来源 | JSON | 二维码 | 说明 |
| --- | --- | --- | --- |
| Apple iTunes 歌曲试听 | `apple-itunes-preview.json` | `apple-itunes-preview.png` | 搜索接口返回的仅是试听片段，不是完整歌曲；不支持翻页。 |
| 央广电台直播 | `cnr-radio.json` | `cnr-radio.png` | 包含中国之声、音乐之声、经典音乐广播和经济之声，各使用一条 HTTPS 直播线路。 |
| 试听与央广组合 | `combined-starter.json` | `combined-starter.png` | 一次确认导入以上两个来源；需要支持多来源包的新版本。 |
| 原版全量 FM | `all-fm.json` | 无 | 原版 173 条电台、581 条线路（含备用），文件导入；需要支持备用线路的新版本。 |

二维码直接包含对应 JSON 的内容，无须下载远程配置。来源由第三方提供，可能因地区、网络、接口或授权变化而不可用；导入前请自行确认平台条款以及播放、录音、导出等用途所需权限，导入不代表取得授权。Apple 试听片段的使用还应遵守 Apple 对预览内容的相关条款。

全量 FM 来自项目 `backup` 分支的旧目录，未逐条验证当前可用性；其中含 HTTP 线路，导入时会提示明文风险。它的体积超过单个二维码的容量，因此须通过文件导入；上面的组合二维码仅包含试听及四台央广直播，不包含全量 FM。

2026-11-09 检查：上述搜索接口返回了歌曲试听地址，四个电台地址返回了 HLS 播放列表；这不代表设备上播放、听感或权限已经验证。Apple 搜索结果中的试听时长及可用性由服务方决定，应用当前无法自动识别试听。需要完整歌曲的服务须直接在搜索结果中提供合法可访问的播放地址；当前格式不支持登录、单独解析播放地址或复杂签名，不能直接兼容网易云、QQ 等全部平台。

配置格式和安全限制见 [`../provider-format.md`](../provider-format.md)。请勿在配置或二维码中放入账号凭据。

## 加密来源文件

支持加密文件的新版应用可导入 `.8dp` 文件。使用 JDK 17 或更高版本，在交互式终端运行：

```powershell
java docs/provider/EncryptProvider.java docs/provider/all-fm.json all-fm.8dp
```

程序会要求输入并确认密码，不会覆盖已有输出文件。导入时输入同一密码；文件使用 PBKDF2-HMAC-SHA256 派生密钥及 AES-256-GCM 认证加密。文件加密不证明来源可信，导入预览仍需核对来源。应用保存的来源配置仍是应用私有数据，文件加密不等同于对应用内部数据或账号凭据加密。
