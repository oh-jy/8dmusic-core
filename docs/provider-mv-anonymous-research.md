# 匿名 MV 播放调研

调研日期：2026-11-25。测试使用本机网络，不携带账号 Cookie；平台接口及地区限制可能变化。

## 样本结果

网易云、QQ 音乐、酷狗各抽取 3 条 MV，通过各自平台接口取得媒体地址。使用 ffprobe 实际读取媒体信息，每条样本均发现 H.264 视频轨和 AAC 音轨。网易云样本中包括搜索结果 `fee=1` 的歌曲；网易云“演员”样本的歌曲音频接口返回 `code=-110`、没有地址，但 MV 详情接口返回了媒体地址。

这只证明抽样接口可匿名访问且媒体头包含音轨；没有验证全部媒体完整下载、音频全长与歌曲版本一致、Android 设备实际播放或其他地区的可用性。歌曲会员标记也不代表其对应 MV 一定受同样权限限制。不可将结果推广为所有歌曲免登录可播放。

## 平台与实现

| 平台 | 匿名 MV 接口 | 现有实现 | 样本 |
| --- | --- | --- | --- |
| 网易云 | `GET https://music.163.com/api/mv/detail?id=...` | `NeteaseProvider.mvOptions` | 演员，MV ID `420144` |
| QQ 音乐 | `POST https://u.y.qq.com/cgi-bin/musicu.fcg`，`music.stream.MvUrlProxy/GetMvUrls` | `QqProvider.mvOptions` | 晴天，视频 ID `w0026q7f01a` |
| 酷狗 | `GET https://m.kugou.com/app/i/mv.php` | `KugouProvider.mvOptions` | 晴天，MV hash `BBAD7DF8DE41B034208A56017BF894A4` |

接口属于平台实际使用接口，并非已确认的公开稳定契约。媒体地址往往有时效或访问限制，不应保存到文档或日志。平台可调整权限、地区、格式、鉴权或接口。

Provider 源码位于独立仓库 `D:/temp/tools/8dmusic-provider/provider-project/`，宿主工程的 `MainActivityPlayback.kt` 在歌曲地址解析失败且搜索结果自带 MV 标识时，已自动尝试将 MV 作为音频播放；`ProviderMvCache.kt` 会先完整下载视频，校验同时含音轨和视频轨，再交给播放器。因此当前体验不是边下载边播放，且音频成功解析但后续解码失败时未必触发该回退。

## 建议

1. 优先验证真实设备：每个平台覆盖普通歌曲、标记会员歌曲、无 MV 歌曲及有登录限制歌曲，记录匿名解析、全长、歌曲版本和实际听到的音频。
2. 改善已有回退：音频解析或实际播放失败时，在平台允许访问且明确标明来源的前提下尝试该歌曲对应 MV；无匹配或受限时明确提示，不绕过平台访问控制。
3. 降低等待与流量：评估 Android 播放器直接读取远程 MV 音轨的可行性，并验证 HTTP 范围请求、失效链接、取消与后续缓存；不能假设所有格式支持边下边播。
4. 搜索结果缺少 MV 标识时，若增加 MV 检索，应核对歌曲名、歌手、版本及长度，避免现场版、翻唱或同名歌曲错播；低置信度时让用户确认。
